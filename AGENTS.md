# Project Knowledge

**Sonoscan Healthcare** — corporate website for a diagnostic centre in West Bengal (4 branches: Kolkata, Malda, Balurghat, Gangarampur).

## Quickstart
- **Package manager**: pnpm
- **Setup**: `pnpm install`
- **Dev**: `pnpm dev` (Vite on port 5173, host 0.0.0.0)
- **Build**: `pnpm build` (runs `tsc -b` then `vite build`)
- **Lint**: `pnpm lint` (oxlint — no ESLint/Prettier)

## Architecture

### Key directories
- `src/routes/` — TanStack Router v1 file-based routing (auto-generates `routeTree.gen.ts`). Each file = one route via `createFileRoute`. Dynamic params use `$` in filenames.
- `src/features/` — Feature modules: page components + optional zod schemas. Lazy-loaded from routes.
- `src/data/` — Static content: doctors (44 across 8 departments), branches (4), services, outdoor doctors (370), galleries, etc.
- `src/features/ui/` — Reusable components: Layout (Navbar, Footer), DoctorCard, CountUp, Reveal, SEO, etc.
- `src/context/` — BranchContext (global branch selection via `useBranch()`)

### Data flow
- No state management library — component-local state with `useState`/`useEffect`
- No API layer — static content only
- BranchContext shares selected branch across navbar, appointments, contact pages

## Conventions

### TypeScript
- `verbatimModuleSyntax: true` — must use `import type` for type-only imports
- `erasableSyntaxOnly: true` — **no enums, no namespaces**
- `noUnusedLocals` / `noUnusedParameters` — no unused vars
- Always run `tsc -b` (project references), not bare `tsc`

### Styling
- **Tailwind CSS v4** — `@import "tailwindcss"` + `@theme` tokens, no PostCSS config
- Custom animations defined in `src/index.css` as `@keyframes` + `.animate-*` utilities
- Inter font loaded from Google Fonts
- Violet/purple theme with custom shade scale

### Routing
- Static routes (`services/kolkata.tsx`) automatically outrank dynamic ones (`services/$id.tsx`)
- Feature pages use `lazyRouteComponent(() => import('...'))` with default exports
- `routeTree.gen.ts` is committed — regenerated by the Vite plugin on dev/build

### Data conventions
- Service IDs are legacy (`primary-care`, `mental-health`, `dental-care`, `eye-care`) — **do not rename**
- Doctor data exports three formats: `doctorsData` (full profiles), `teamMembers` (cards), `appointmentDoctors` (booking)
- OPD roster in `outdoorDoctors.ts` — 370 doctors across 4 branches

## Things to avoid
- Do NOT install ESLint or Prettier — oxlint handles linting
- Do NOT use `enum` or `namespace` keywords
- Do NOT run `tsc` without `-b` flag
- Do NOT rename legacy service IDs
- Do NOT delete `routeTree.gen.ts` — it's needed for build
