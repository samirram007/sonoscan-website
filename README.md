# Sonoscan Healthcare — Website

Corporate website for **Sonoscan Healthcare**, a diagnostic centre in West Bengal offering pathology, radiology & imaging, multi-specialty OPD, and health check packages across four branches (Kolkata, Malda, Balurghat, Gangarampur).

## Tech Stack

- **React 19** + **TypeScript 6**
- **Vite 8** — dev server & bundler
- **TanStack Router v1** — file-based routing via `@tanstack/router-plugin` (Vite plugin, auto-generated `routeTree.gen.ts`)
- **Tailwind CSS v4** — `@import "tailwindcss"` + `@theme` tokens, custom animations
- **Zod** — runtime schemas for page content models
- **Oxlint** — linting (no ESLint/Prettier)
- **Package manager**: pnpm (`pnpm-lock.yaml`)

## Getting Started

```bash
pnpm install     # install dependencies
pnpm dev         # start dev server on http://localhost:5173 (host 0.0.0.0)
pnpm build       # type-check (tsc -b) then production build
pnpm preview     # preview the production build
pnpm lint        # run oxlint
```

## Project Structure

```
src/
├── routes/          # File-based routes: each file = one route (createFileRoute)
│   ├── __root.tsx   # Root layout, 404, pending component
│   ├── index.tsx    # / (home, eager)
│   ├── services/    # /services, /services/$id, /services/{kolkata,malda,balurghat,gangarampur}
│   ├── doctors/     # /doctors, /doctors/$slug
│   ├── about.tsx pricing.tsx appointments.tsx gallery.tsx contact.tsx privacy.tsx terms.tsx cookies.tsx
│   └── routeTree.gen.ts  # auto-generated by the Vite plugin (committed)
├── features/        # Feature modules: page component + optional zod schema
│   ├── home/ about/ services/ pricing/ doctors/ appointments/ branches/ gallery/ contact/ legal/
│   └── ui/          # Reusable UI: Layout, DoctorCard, CountUp, Reveal, SEO, ServiceIcons, ...
├── data/            # Static content: doctors (44), branches (4), services, home, contact, ...
├── context/         # BranchContext — globally selected branch (navbar, appointments, contact)
├── main.tsx         # Entry point — creates router from routeTree.gen, renders <RouterProvider>
└── index.css        # Tailwind v4 setup, theme tokens, all @keyframes + .animate-* classes
```

## Features

- **Home page** — hero, stats (CountUp), benefits, core values, testimonials, services grid
- **Services** — listing at `/services`, detail pages at `/services/$id` with pricing sidebar & specialists
  - Legacy IDs map to display titles: `primary-care` → Pathology & Lab Diagnostics, `mental-health` → Radiology & Imaging, `dental-care` → Multi-Specialty OPD, `eye-care` → Health Check Packages
- **Doctors** — listing at `/doctors`, profiles at `/doctors/$slug` with quick stats, career timeline, OPD schedule calendar, patient reviews, related doctors
- **Branches** — detail pages at `/services/kolkata|malda|balurghat|gangarampur` (static routes, take priority over dynamic `/services/$id`)
- **Appointments** — multi-step booking flow filtered by the selected branch
- **Pricing, Gallery, About, Contact, Legal** pages (Privacy / Terms / Cookies)

## Conventions & Gotchas

- **File-based routing**: every file in `src/routes/` maps to a route via `createFileRoute('<path>')`. Dynamic params use `$` in filenames (`services/$id.tsx`, `doctors/$slug.tsx`). Static files (e.g. `services/kolkata.tsx`) automatically outrank dynamic ones. `routeTree.gen.ts` is auto-generated and committed (not gitignored) — keep it, since `pnpm build` runs `tsc -b` before the plugin runs.
- **Do not rename the legacy service IDs** (`primary-care`, etc.) — routing depends on them.
- TypeScript: `verbatimModuleSyntax` (use `import type`), `erasableSyntaxOnly` (no `enum`/`namespace`), `noUnusedLocals`/`noUnusedParameters`. Always run `tsc -b` (project references).
- No ESLint/Prettier — oxlint only; Tailwind class ordering is not enforced.
- No state management library or API layer yet — static content + component-local state.
